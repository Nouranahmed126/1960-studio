# 1960 STUDIO

نسخة تأسيسية عربية ومتجاوبة مع الهاتف، مبنية بـ Next.js وSupabase.

## التشغيل

1. `npm install`
2. انسخ `.env.example` إلى `.env.local` وأضف Project URL و**publishable/anon key فقط** من Supabase.
3. نفّذ ملف `supabase/registration.sql` في SQL Editor بعد مراجعته.
4. `npm run dev`

## النشر

اربط المستودع بـ Vercel واضبط متغيرات البيئة هناك. لا ترفع `.env.local` ولا `service_role` key على GitHub أو للمتصفح.

## ما تم

- تسجيل طالب بالاسم الثلاثي والبريد وكلمة المرور.
- اختيار 2–3 فرق وإرسالها عبر RPC محمية.
- شاشة انتظار الموافقة.
- لوحة مشرفة مبدئية للموافقة على الطالب وعضوياته.

## ما لم يكتمل بعد

- التكليفات والمساهمات والملفات والمراجعات، والقيادة داخل كل فريق.
- اختبارات شاملة لـ RLS والتخزين، وتجربة البريد الإلكتروني والتسجيل.
- اختبار البناء والنشر الفعلي على Vercel.

**مهم:** لا تشاركي الرابط مع الطلاب قبل اختبار التسجيل والصلاحيات بحسابات تجريبية.
