# الخطوات التالية — 1960 STUDIO

1. مراجعة وتنفيذ `supabase/registration.sql` في مشروع Supabase بعد التأكد من التوافق مع الجداول الحالية.
2. إعداد متغيرات Supabase العامة في بيئة النشر دون نشر أي مفتاح سري.
3. اختبار تسجيل طالب تجريبي واختيار فريقين أو ثلاثة ثم موافقة المشرفة.
4. اختبار منع الطالب غير المعتمد من الاطلاع على ملفات الفرق.
5. تطوير التكليفات والمساهمات والملفات، ثم اختبار البناء والنشر.

لا تشاركي الموقع مع الطلاب قبل نجاح اختبارات الصلاحيات.
