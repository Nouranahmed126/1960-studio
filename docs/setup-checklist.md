# تفعيل التسجيل والموافقات

1. راجعي ونفّذي `supabase/team-approval.sql` في SQL Editor بمشروع Supabase، بعد التأكد من وجود الجداول والسياسات المذكورة فيه.
2. أضيفي `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` إلى إعدادات بيئة النشر في Vercel. لا تضعي `service_role` في الموقع.
3. اختبري إنشاء طالب تجريبي واختيار فريقين أو ثلاثة. إذا كان تأكيد البريد مفعلًا، أكدي البريد ثم ادخلي الحساب لاستكمال الطلب.
4. لا تفتحي التسجيل للطلاب حتى يكتمل مسار تأكيد البريد واختبار الموافقات وRLS.

**ملاحظة:** ملف SQL لم يُنفّذ على قاعدة البيانات تلقائيًا بمجرد رفعه على GitHub.
